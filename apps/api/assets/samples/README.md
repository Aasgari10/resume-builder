# Sample pictures

Shown in previews wherever the user has not added their own picture (see `packages/templates/src/sample.ts`).
Served at `/_assets/samples/` by the API. File names are fixed; replace a picture by saving a new `.jpg` with the same name.

Before public launch, replace these demo pictures with free-to-use photos (for example from pexels.com),
because their license is unknown: avatar, about, project-dashboard, project-dashboard-2, project-components,
project-music, project-portfolio. The certificate pictures were drawn for this project and can stay.

Grogin (`gg-*`): every picture, icon and the logo come from the Grogin theme demo (KLBTheme) and are
only for local development. Replace all of them, and the name and logo, before the template is published.

Juno (`jn-*`): every picture, the logo and the decorations come from the Juno theme demo (ThemeREX) or
were cut from its screenshots; only for local development. Replace all of them, and the name and logo,
before the template is published.
